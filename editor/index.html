    设置 GitHub Token

    在线编辑器通过 GitHub API 把改动提交到仓库 ，因此需要你自己的 Token。 Token 只保存在本机浏览器（localStorage），不会写入网站或仓库，也没有其他人能看到。

    1. 打开 Fine-grained token 创建页
    2. Repository access 选 Only select repositories → 勾选
    3. Permissions → Repository permissions → Contents: Read and write
    4. 生成后粘贴到下面
